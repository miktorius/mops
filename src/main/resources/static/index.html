    Отправить событие

    Можно ввести событие вручную. Зарегистрированный обработчик без перехода выполнится без смены состояния.

    События

    Новое событие получает стандартный обработчик: запись данных в лог и выполнение настроенного перехода.

    Удаление события также удаляет все переходы по нему. Сообщения с этим событием, ожидающие в очереди, будут отклонены.

      Состояния

      Назначение начального состояния не перемещает текущий автомат. Конечные состояния не принимают события; перед отметкой «конечное» удалите исходящие переходы.

      Текущее и начальное состояния удалить нельзя. При удалении другого состояния удаляются связанные переходы.

        Переходы

        Выберите зарегистрированное событие. Один переход на пару «исходное состояние + событие». Для замены перехода удалите его и добавьте новый.
