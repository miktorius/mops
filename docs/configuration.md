# Контракт конфигурации

Корневой YAML содержит списки `classes`, `objects`, `roles`, `users`, `processes`.
Модель включения нового комплектующего (вариант 1) находится в
`src/main/resources/process-model.yaml`.
Все идентификаторы — строки. Неизвестные поля отклоняются. Названия `title` и `name`
служат для отображения, идентификаторы используются в ссылках и командах.

## Классы и объекты

Класс: `id`, необязательные `title`, `parent`, `parameters`.
Параметр: `id`, `type`, необязательные `title`, `min`, `max`, `default`,
`quantity_min`, `quantity_max`.

Типы скалярных параметров: `integer`, `decimal`, `string`.
Для состава в `type` указывается идентификатор класса связанных объектов.
Значение состава — список идентификаторов объектов этого класса или подклассов.
Незаданный состав (включая явный `null`) становится пустым списком.

Класс наследует параметры единственного родителя. Параметр с совпадающим `id`
полностью заменяет описание родителя, сохраняя тип. Границы и `default` из старого
описания при переопределении не сохраняются, если не указаны снова.

Объект: `id`, `class`, необязательный словарь `values`.
Для пропущенных скалярных параметров применяется `default`, иначе значение — `null`.
Явный `null` не заменяется значением по умолчанию. Объект с числом за пределами
диапазона загружается; диапазон проверяется предикатом `in_range`.

## Пользователи и роли

Роль: `id`, необязательный `title`.
Пользователь: `id`, необязательный `name`, список `roles`.
Для выполнения достаточно одной роли из разрешённых. Пользователь выбирается
в интерфейсе или передаётся в команде; пароли и аутентификация не требуются.

## Шаблоны

Элемент `processes` содержит:

| Поле | Содержимое |
|---|---|
| `process` | Идентификатор шаблона |
| `title` | Необязательное название |
| `class` | Точный класс объекта |
| `create_roles` | Список ролей для запуска |
| `actions` | Список действий: `id`, необязательный `title` |
| `predicates` | Список предикатов |
| `states` | Список состояний |
| `transitions` | Список переходов |

Для класса допускается один шаблон. Шаблоны не наследуются: объект подкласса
не использует шаблон родителя автоматически.

Состояние: `id`, необязательные `title`, `initial`, `final`, `roles`.
Флаги по умолчанию ложны. Начальное состояние ровно одно; конечных может не быть
или быть несколько. Роли текущего состояния разрешают выполнение действий.
Конечное состояние не принимает действия.

Переход: `from`, `action`, `to`, необязательное `condition`.
Условие — ДНФ, например `[[a, not b], [c]]`: `(a И НЕ b) ИЛИ c`.
Вложенные элементы — строки с идентификаторами предикатов; `not ` отрицает предикат.
Отсутствующее условие истинно, `condition: []` ложно, `condition: [[]]` истинно.
Если подходят два разных перехода, возвращается `error`, состояние сохраняется.
Несколько истинных групп одного условия разрешают один переход.

## Предикаты

Предикат параметра: `id`, `parameter`, `operator`, необязательные `value`, `aggregate`.
Для предиката класса укажите только `id` и `class`: результат истинен для объекта
этого класса и подклассов.

| Оператор | Семантика |
|---|---|
| `filled` | Значение не `null`; пустая строка задана, пустой состав не заполнен |
| `'='`, `'!='` | Равенство и неравенство |
| `'<'`, `'<='`, `'>'`, `'>='` | Сравнение чисел |
| `in_range` | Диапазон описания параметра фактического класса объекта |

Для состава в сравнении участвует число элементов, а `in_range` проверяет
`quantity_min`/`quantity_max`. Отсутствующая граница не проверяется. Для числа
используются `min`/`max`. Числа сравниваются через `BigDecimal`.
Операторы `filled` и `in_range` не требуют `value`.

Незаданное значение или отсутствующий параметр дают `false` для любого оператора,
включая `!=`. Оператор `not` отрицает уже полученный результат.

Путь `состав.параметр` обращается к параметру каждого связанного объекта.
Поддерживается один уровень, поле `aggregate` обязательно:

- `all` — истинно для всех результатов, включая пустую последовательность;
- `any` — истинен хотя бы один результат; для пустой последовательности ложно.

Границы для пути берутся из фактического класса каждого связанного объекта,
с учётом наследования и переопределения. Неподдерживаемое имя агрегатора — ошибка
при запуске приложения. Стратегии задаются реестром функций в `Conditions`.
